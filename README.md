# LP e-Queijo

Landing page responsiva baseada no layout do Figma, construída em HTML, CSS e JavaScript sem dependências.

## Publicação na Vercel

1. Importe este repositório na Vercel.
2. Selecione **Other** como framework.
3. Não informe comando de build.
4. Mantenha o diretório de saída vazio ou como raiz (`.`).

## Link de contato

Atualize a constante `contactUrl` em `script.js` com o WhatsApp ou formulário definitivo do cliente.
